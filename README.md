# Welcome to My Tetris
***

## Task
we had to recreate the famous tetris game, with rotation, clear line...
we had to make piece of different shape and color 
we could had add the original music 

## Description
i first created the playfield and the piece with that i created the drop piece systeme then i made a clear line function after all that i created a hold function

## Installation
you don't have anything to install you can play with it with the html file 

## Usage
you can just click on start and the game will start
left and right arrow to move the piece
down arrow to soft drop the piece (make it drop faster than normal)
space to hard drop the piece 
r to rotate the piece
h to hold the piece

and to go in "hard secret jojo mod" you can type at any moment: jojo. the game become faster but you earn a time stop ability for 3 second, where you can move the piece, usable every 15 second
there are also secret code hidden in the easter eggs file.
